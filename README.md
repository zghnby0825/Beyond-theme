## ✨ 主题特性

- 🔢 **数字上滑** —— `Q`–`P` 上滑即输入 `1`–`0`，不用切数字页
- ➗ **符号下滑** —— 同一排下滑输入 `% + * & ± × \ ¥ ° $`
- 👆 **长按候选** —— 长按弹出该键的候选（数字 / 大写 / 全角字符等）
- 📏 **紧凑布局** —— 横向键距 2、纵向键距 6，键帽更大更好按；整行宽度依旧铺满屏幕
- ⌨️ **三套键盘页** —— 中文 `default`、英文 `english`、数字符号 `number`
- 🎨 **自制矢量图标** —— 语音识别 / 表情 / 剪贴板 / 中英切换，任何分辨率都清晰
- 🌑 **无阴影键帽** —— 纯色键帽 + 圆角 8，界面干净利落

## ⌨️ 键盘布局

### 中文页 `default`

| 行 | 内容 |
| :-- | :-- |
| 顶栏 | 语音识别 · 表情 · 剪贴板 · 中英切换 |
| 1 | `Q W E R T Y U I O P` —— 上滑 `1`–`0`，下滑符号，长按候选 |
| 2 | `A S D F G H J K L` —— 上滑 `~ / : ; ( ) @ " '`；`G` 下滑打开工具面板（全选 / 剪切 / 复制 / 粘贴 / 清空 / 重建主题） |
| 3 | `Shift`（1.5 键宽）+ `Z X C V B N M` + `⌫`（1.5 键宽，上滑清空全部、下滑撤销） |
| 4 | `?123`(2) · `，`(1) · `空格`(4，上滑切英文、双击「。」) · `；`(1，上滑 Tab) · `搜索 / 回车`(2，上滑剪贴板，长按清空·撤销·重做·下一候选) |

> `?123` 是上下文键：无候选时切符号页，有候选时输入半角逗号，编码中触发**小鹤音形反查**。
>
> `，` 长按可打出 `，。！？：@……` 与反查。

### 英文页 `english`

- 第 1 排上滑同样输入数字 `1`–`0`，与中文页保持同一手感
- 第 4 排：`?123` · `,` · `space`（上滑切回中文）· `;` · `return`

### 数字页 `number`

- 左侧符号表（`+ - × / % = , # ? . : *`）+ 九宫格数字 `1`–`9`、`0`，附空格与回车

## 🚀 导入方法

1. 下载本仓库（`Code` → `Download ZIP`，或 `git clone`），或直接到 [Releases](https://github.com/zghnby0825/HarmonyNEXT_Rime_input_647Uni/releases) 下载打包好的 `xhyx_1011.zip`
2. 把主题文件夹 `小鹤主题` 压缩成 `.zip`
3. 打开超越输入法 → 主题 → 导入，选择该 zip 即可

> `theme.yaml` 通过相对路径 `./../public/...` 继承输入法内置的公共资源（样式、字体、配色、公共按键），请勿改动目录层级与这些路径。
>
> 主题文件夹于 2026-10-11 由 `小鹤主题_0904` 改名为 `小鹤主题`，内容持续更新，最新改动见下方「更新记录」。

## 🎛️ 想自己改？

常用旋钮都在 `小鹤主题/theme.yaml` 的 `preset_keyboards:` 下：

| 参数 | 作用 | 当前值 |
| :-- | :-- | :-- |
| `horizontal_gap` | 按键横向间距（调小 → 键更宽，整行仍铺满屏幕） | `2` |
| `vertical_gap` | 行与行之间的纵向间距（横屏为 `vertical_gap_land`） | `6` |
| `height` / `height_land` | 键高（竖屏 / 横屏） | `46` / `34` |
| `round_corner` | 键帽圆角 | `8` |
| `width` | 键盘宽度（= 字母键宽的倍数） | `10` |
| `shadow` | 键帽阴影（当前全 0，即无阴影） | `0` |

每个按键都支持 `swipe_up`（上滑）、`swipe_down`（下滑）、`long_click`（长按候选），例如：

```yaml
- { click: q, label: "Q", swipe_up: "1", swipe_down: "%", long_click: [ "1", commit_q, commit_Q ] }
```
