## 和「小鹤万象」的区别

- **字母页多一行数字**：`default` / `english` / `symbols` 三页顶部都是 `1 2 3 4 5 6 7 8 9 0`，不用切页就能敲数字
- **九宫格独立成页**：`number` 页，左侧符号表 + 九宫格数字
- **键高更紧凑**：字母页 `height: 40`（常规主题是 46），九宫格页 `height: 51`

## 键盘布局（4 套键盘）

| 页面 | 键数 | 结构 |
| :-- | :-- | :-- |
| `default` | 45 | 数字行 `1`–`0` → `Q W E R T Y U I O P` → `A S D F G H J K L` → `Shift` + `Z`–`M` + `⌫` → 底排 `符号`20 · `，`10 · `空格`40 · `/`10 · `回车`20 |
| `english` | 45 | 与 `default` 同一骨架；第 4 行末尾用 `符` 与半角逗号键，底排同样是 `20 + 10 + 40 + 10 + 20 = 100` 份 |
| `number` | 20 | 左侧符号表 `17` + 九宫格 `1`–`9` + `⌫`17；第二、三行左侧留空、配 `4 5 6` / `7 8 9`；底排 `符`17 · `返回`22 · `0` · `空格` · `回车`17，合计 100 份 |
| `symbols` | 45 | 数字行 + 符号行 `% + * & ± × \ ¥ ° $` → 更多半角/全角符号 → `更多符`15 + 7 个符号 + `⌫`15 → 底排 `返回`20 · `123`10 · `空格`40 · `，`10 · `回车`20 |

> 底排宽度都是 `100` 份，正好等于 10 个字母键宽，与上面几行同宽。

## 导入方法

1. 下载本分支（`Code` → `Download ZIP`，或 `git clone -b 小鹤万象number（超越）`）
2. 把主题文件夹 `小鹤万象number（超越）` 压缩成 `.zip`
3. 打开超越输入法 → 主题 → 导入，选择该 zip
4. 导入后主题名显示为「万象主题(number)」

> `theme.yaml` 通过相对路径 `./../public/...` 继承输入法内置的公共资源（样式、字体、配色、公共按键、符号页菜单），**请勿改动目录层级与这些路径**；`themes_data/bottom_func_keys.yaml` 必须跟着主题文件夹一起导入。
